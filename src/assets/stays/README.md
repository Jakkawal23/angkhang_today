# รูปที่พัก

ใส่เฉพาะรูปที่ **ได้รับอนุญาต** แล้วเท่านั้น (เจ้าของที่พักส่งให้ / ถ่ายเอง / ไลเซนส์อนุญาตให้ใช้)

```
src/assets/stays/<slug>/
  01.jpg 02.jpg ...      รูปรวม (01 = รูปปก)
  rooms/1/01.jpg ...     รูปห้องพักประเภทที่ 1 (ตามลำดับ rooms ใน scripts/real-stays.mjs)
  credits.json           เครดิตและคำอธิบายรูป
```

นำเข้ารูป (ย่อขนาด หมุนตาม EXIF ลบพิกัด GPS ตั้งชื่อให้อัตโนมัติ):

    node scripts/add-photos.mjs <slug> "<โฟลเดอร์รูป>" --credit "ภาพจากเจ้าของที่พัก"
    node scripts/add-photos.mjs <slug> "<โฟลเดอร์รูปห้อง>" --room 1

ตอน build ระบบแปลงเป็น WebP หลายขนาดให้เอง ไม่ต้องย่อเอง
