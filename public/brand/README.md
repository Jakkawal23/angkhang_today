# โลโก้ Angkhang Today

สัญลักษณ์มาจากไฟล์ออกแบบของเจ้าของแบรนด์ (Canva) ที่ trace เป็นเวกเตอร์จริงแล้ว เก็บที่ `src/data/logo-traced.json`
แล้วสร้างทุกไฟล์ด้วย `npm run logo`

ถ้าเปลี่ยนแบบโลโก้: `npm run logo:trace -- "<ไฟล์สัญลักษณ์ใหม่.svg หรือ .png>"` แล้ว `npm run logo`

| ไฟล์ | ใช้กับ |
| --- | --- |
| `logo-symbol.svg` | ต้นฉบับสัญลักษณ์ (เวกเตอร์) — ส่งให้โรงพิมพ์/นักออกแบบ |
| `logo-symbol-white.svg` | สัญลักษณ์สำหรับพื้นเข้ม |
| `logo-horizontal.svg` / `.png` (1600px) | หัวเว็บ เอกสาร ป้าย — สัญลักษณ์ซ้าย ตัวหนังสือ 2 บรรทัดขวา |
| `logo-horizontal-white.svg` / `.png` | แบบแนวนอนบนพื้นเข้ม |
| `logo-square.svg` / `.png` (1024px) | โปรไฟล์ LINE OA, Facebook, ไอคอนแอป — ไม่มีตัวหนังสือ |
| `logo-square-text.svg` / `.png` (1024px) | โพสต์ โปสเตอร์ สติกเกอร์ — สัญลักษณ์บน ตัวหนังสือล่าง |
| `logo-symbol-512.png` | สัญลักษณ์พื้นใส |
| `/favicon.svg`, `/favicon-32.png`, `/apple-touch-icon.png` | ไอคอนเว็บและหน้าจอมือถือ |

## ความหมาย (สไตล์เส้นโครง)

- **โล่** — ความน่าเชื่อถือ ช่องทางติดต่อการันตี ปลอดภัยจากเพจปลอม
- **ภูเขาสองลูก** ที่สันเขาตวัดขึ้นเป็น **เครื่องหมายถูกทะลุขอบโล่** — ตรวจสอบแล้ว และก้าวไปข้างหน้า
- **เส้นหมอก** — ทะเลหมอกดอยอ่างขาง
- **ถนนคดเคี้ยว** — เส้นทางขึ้นดอย การหาและการเดินทาง
- **ดวงอาทิตย์สีชมพูซากุระ** — "Today" เช้าวันใหม่ อนาคตของการท่องเที่ยวอ่างขาง
