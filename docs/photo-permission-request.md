# ข้อความขออนุญาตใช้รูปและยืนยันข้อมูลที่พัก

ส่งทาง LINE / Messenger / โทร ของที่พักแต่ละแห่ง (ดูช่องทางในหน้าที่พักบนเว็บ) แก้ `[...]` ก่อนส่ง

---

สวัสดีค่ะ/ครับ ติดต่อจาก **Angkhang Today (อ่างขาง ทูเดย์)** เว็บรวมที่พักดอยอ่างขางและเส้นทางขึ้นดอย
ที่ช่วยให้นักท่องเที่ยวติดต่อที่พักได้ตรง และป้องกันเพจปลอมหลอกโอนเงิน

เราได้ทำหน้าตัวอย่างของ **[ชื่อที่พัก]** ไว้ที่ [ลิงก์หน้าที่พัก] จากข้อมูลสาธารณะ จึงอยากขอ

1. **ยืนยันข้อมูล** — ประเภทห้อง จำนวนห้อง ราคา เบอร์โทร LINE เพจ และพิกัด Google Maps ถูกต้องไหม
2. **อนุญาตให้ใช้รูป** — ส่งรูปที่พักและรูปแต่ละห้อง (5–15 รูป แนวนอน) หรืออนุญาตให้ใช้รูปจากเพจของที่พัก
   โดยเราจะใส่เครดิต "ภาพจาก [ชื่อที่พัก]" ทุกรูป
3. (ถ้าสะดวก) **ยืนยันชื่อบัญชีรับโอน** เพื่อรับเครื่องหมาย "การันตีช่องทางติดต่อ"

ลงข้อมูลฟรี ไม่มีค่าคอมมิชชั่น ลูกค้าติดต่อและโอนเงินให้ที่พักโดยตรง
ถ้าไม่ต้องการให้แสดงข้อมูลบนเว็บ แจ้งได้เลย เราจะนำออกทันทีค่ะ/ครับ

ขอบคุณค่ะ/ครับ
[ชื่อผู้ติดต่อ] · Angkhang Today · LINE [@angkhangtoday]

## เมื่อได้รับอนุญาตแล้ว

1. เก็บหลักฐานการอนุญาต (แคปแชต) ไว้ที่ `docs/permissions/<slug>/` (ไม่ต้อง commit ขึ้น git ถ้ามีข้อมูลส่วนตัว)
2. นำเข้ารูป: `node scripts/add-photos.mjs <slug> "<โฟลเดอร์รูป>" --credit "ภาพจาก [ชื่อที่พัก]"`
3. แก้ข้อมูลใน `scripts/real-stays.mjs` แล้วเปลี่ยน `status` เป็น `open` และลบคำว่า (ตัวอย่าง) ออกจากชื่อ
4. รัน `node scripts/build-stays.mjs`
